# Gauteng service boundary

`gauteng.geojson` is the Gauteng feature extracted from geoBoundaries' simplified South Africa ADM1 dataset, boundary ID `ZAF-ADM1-76434192`, representing 2020 boundaries.

Sources: OCHA ROSEA and South African Municipal Demarcation Board, distributed by geoBoundaries. Licensed under Creative Commons Attribution 3.0 IGO.

- Metadata: https://www.geoboundaries.org/api/current/gbOpen/ZAF/ADM1/
- Original source: https://data.humdata.org/dataset/south-africa-admin-level-1-boundaries
- Download: https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/ZAF/ADM1/geoBoundaries-ZAF-ADM1_simplified.geojson
- License: https://creativecommons.org/licenses/by/3.0/igo/

The geometry is simplified, so addresses very close to the provincial border may need manual review. Only the Gauteng feature is bundled; coordinates were not otherwise changed.
